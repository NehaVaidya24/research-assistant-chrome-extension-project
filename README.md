
# Research Assistant Chrome Extension

**Research Assistant** is a Chrome extension that helps users instantly summarize, analyze, and organize web content using AI — directly in the browser. It is ideal for students, researchers, professionals, and anyone dealing with large amounts of online information.

> ⚡ Get AI-powered summaries and insights without switching between tabs or tools.

## Features

- 🧠 **AI Summarization** – Generate concise summaries of articles, blogs, and web pages.
- 📌 **Clip & Save** – Save important snippets to your personal knowledge base.
- 📚 **Organize Research** – Create workspaces and tags to manage research for different projects.
- 🔍 **Search Insights** – Quickly search through saved summaries and notes.
- 🔒 **Local Storage** – All data is stored locally — your research stays private.
- 🔑 **API Integration** – Works with your own OpenAI or Anthropic API key for AI features. :contentReference[oaicite:1]{index=1}

## How It Works

1. **Install the Extension**  
   Add the extension to your Chrome browser.

2. **Configure API Key**  
   Provide your OpenAI/Anthropic API key in the extension settings.

3. **Summarize a Page**  
   Go to any page, click the extension icon, and get an instant AI summary.

4. **Save & Organize**  
   Clip insights and organize them into workspaces for faster research management.


## Installation

### Local Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/NehaVaidya24/research-assistant-chrome-extension-project.git
2. Open Chrome and go to:
 - chrome://extensions/

3. Enable Developer Mode.

4. Click Load unpacked and select the project folder.

5. Pin the extension for easy access.

## Configuration

1. Click on the extension icon.

2. Go to Settings.

3. Enter your OpenAI or Anthropic API key.

4. Save and start summarizing!

🛠️ Your API key is never stored on external servers — all processing happens locally or via the API provider you choose.
